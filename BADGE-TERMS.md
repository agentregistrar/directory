# Badge terms

The badge is `Agent signup | Supported`. It is available only to providers listed in Agent Registrar Directory with a passing check.

## What the badge means

- The provider is listed in Agent Registrar Directory.
- The provider's discovery document passed the official Agent Identity Protocol validator at the date shown on the listing page.
- A maintainer reviewed the listing.

## What the badge does not mean

- It does not mean Agent Registrar tested the signup endpoint end to end.
- It does not mean Agent Registrar endorses, certifies, approves, or audits the service.
- It does not mean the service is safe, secure, reliable, or fairly priced.
- It is not a "verified provider" attestation. Verification is a separate, optional broker attestation.
- It is not a guarantee of availability or fitness for any purpose.

## Usage

- Use the badge only while the provider is listed and active.
- Link the badge to the provider's listing page.
- Do not alter the badge text, colors, or dimensions.
- Do not imply certification, partnership, approval, or endorsement.
- Do not use the badge in a way that suggests Agent Registrar operates or guarantees the service.
- Remove the badge if the listing is removed or marked failing.

## Enforcement

The directory may remove the badge file and ask for removal if these terms are violated. The per-entry badge URL stops resolving when the listing is removed or fails for more than the grace period.

## Contact

Use the repository issue templates for badge questions or reports.
